# Фотографии Time Square

Фото выгружены из папки заказчика на Google Drive, отобраны 26 кадров из 58,
сжаты в WebP (ширина до 1920 px, качество 80). Пути и alt-тексты прописаны
в `src/lib/properties.ts`, массив `timeSquare.photos`.

## Что где

| Файлы                       | Категория по ТЗ | Содержание                                        |
|-----------------------------|-----------------|---------------------------------------------------|
| `facade-1…4.webp`           | Фасад с дрона   | `facade-1` — **главное фото**: здание с панорамой на Заилийский Алатау. Дальше вечерняя подсветка и аэросъёмка |
| `entrance-1…2.webp`         | Входная группа  | Вход с улицы, навес, пешеходная зона              |
| `hall-1…4.webp`             | Холл            | Атриум под стеклянным куполом, арт-инсталляция, ресепшн |
| `office-1…6.webp`           | Офисы           | Свободные площади и пример оформления офиса       |
| `common-1…3.webp`           | Общие зоны      | Терраса, кафе, лаунж                              |
| `parking-1…3.webp`          | Паркинг         | Подземный паркинг                                 |
| `render-1…4.webp`           | Рендеры проекта | Двор, кабинет, фасад вечером, входная группа      |

`facade-1.webp` открывает блок Time Square на главной во всю ширину экрана.
Кадр горизонтальный, здание в средней части — заголовок и адрес лежат на
затемнении внизу и ничего не перекрывают.

## Чего не хватает

**Лифты** — в папке заказчика фотографий лифтов нет, поэтому категория
«Лифты» в галерее не выводится. Как появятся кадры, положите их сюда как
`elevators-1.webp` и добавьте строку в `timeSquare.photos`:

```ts
{ src: "/TimeSquare/elevators-1.webp", alt: "Высокоскоростные лифты бизнес-центра Time Square", category: "elevators" },
```

Категория подхватится в фильтр галереи автоматически.

## Как заменить или добавить фото

1. Положите файл в эту папку.
2. Сожмите: `npm run convert-images`
3. Добавьте или поправьте строку в `timeSquare.photos` — доступные категории:
   `facade`, `entrance`, `hall`, `offices`, `elevators`, `common`, `parking`,
   `renders`, `infrastructure`.

Если файла по указанному пути нет, на его месте показывается подписанная
заглушка — вёрстка не ломается.
