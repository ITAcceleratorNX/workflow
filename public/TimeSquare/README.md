# Фотографии Time Square

Положите сюда фотографии из папки заказчика. Пути и alt-тексты уже прописаны
в `src/lib/properties.ts` — если файл с ожидаемым именем есть, он подхватится
автоматически; если файла нет, на его месте показывается подпись категории,
вёрстка не ломается.

## Ожидаемые имена файлов

| Файл                | Категория по ТЗ    | Где используется                          |
|---------------------|--------------------|-------------------------------------------|
| `facade-1.webp`     | Фасад с дрона      | **большое фото объекта на главной**, обложка, галерея |
| `facade-2.webp`     | Фасад с дрона      | галерея                                   |
| `entrance-1.webp`   | Входная группа     | галерея                                   |
| `entrance-2.webp`   | Входная группа     | галерея                                   |
| `hall-1.webp`       | Холл               | галерея                                   |
| `hall-2.webp`       | Холл               | галерея                                   |
| `office-1.webp`     | Офисы              | галерея                                   |
| `office-2.webp`     | Офисы              | галерея                                   |
| `elevators-1.webp`  | Лифты              | галерея                                   |
| `common-1.webp`     | Общие зоны         | галерея                                   |
| `common-2.webp`     | Общие зоны         | галерея                                   |
| `parking-1.webp`    | Паркинг            | галерея                                   |
| `render-1.webp`     | Рендеры проекта    | галерея                                   |
| `render-2.webp`     | Рендеры проекта    | галерея                                   |

`facade-1.webp` — главное фото: оно открывает блок Time Square на главной
странице во всю ширину экрана. Берите горизонтальный кадр фасада, ключевые
элементы здания не должны попадать в самый низ кадра (там лежит затемнение
с заголовком).

## Как добавить фото

1. Скопируйте файлы в эту папку с именами из таблицы.
2. Оптимизируйте их в WebP:

```bash
npm run convert-images
```

Скрипт пройдёт по `public/`, сожмёт изображения и сохранит `.webp`
(исходные `.jpg`/`.png` после конвертации можно удалить).

## Если фото больше или меньше

Список изображений и alt-тексты — в `src/lib/properties.ts`, массив
`timeSquare.photos`. Добавляйте строки с нужной категорией:
`facade`, `entrance`, `hall`, `offices`, `elevators`, `common`, `parking`,
`renders`, `infrastructure`.
